# Hardware Website

## Overview
This project is a hardware website designed to showcase products and provide information about the company "KINOTI GK HARDWARE NKUBU." The website features a modern and engaging design with a primary color scheme of orange, complemented by accents of green and red.

## Project Structure
```
hardware-website
├── assets
│   ├── css
│   │   └── style.css
│   ├── js
│   │   └── script.js
│   └── images
│       └── logo.png
├── index.html
└── README.md
```

## Files Description
- **index.html**: The main HTML document that includes the structure of the webpage, featuring a navigation bar with links to "HOME", "ABOUT", "PRODUCTS", "PHOTO GALLERY", "CAREER", "CONTACT", and "CUSTOMER REVIEW". It also contains a search bar positioned at the top right and references the CSS and JavaScript files.

- **assets/css/style.css**: Contains the CSS styles for the website, defining the primary color scheme and styles for the navigation bar, search bar, and other elements to create an engaging design.

- **assets/js/script.js**: Includes JavaScript code for interactive features on the website, such as handling the search functionality or dynamic content updates.

- **assets/images/logo.png**: The company logo image used in the website's header or navigation bar.

## Setup Instructions
1. Clone the repository to your local machine.
2. Open the `index.html` file in a web browser to view the website.
3. Modify the CSS and JavaScript files as needed to customize the design and functionality.

## Additional Information
This project aims to provide a user-friendly experience for customers looking for hardware products. The design is responsive and visually appealing, ensuring that users can easily navigate through the website and find the information they need.
